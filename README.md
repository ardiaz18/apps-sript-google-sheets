# Apps Script para Google Sheets

Colección de scripts de Google Apps Script y notebooks auxiliares para automatizar tareas en Google Sheets.

## Scripts incluidos

| Script | Tipo | Descripción |
|---|---|---|
| [get-doc-title](get-doc-title/) | Apps Script | Función personalizada que devuelve el título de un Google Doc desde su URL |
| [prevision-semanal-tareas-pasadas](prevision-semanal-tareas-pasadas/) | Apps Script | Mueve tareas marcadas como "Hecho" a una hoja de histórico con fecha |
| [buscar_en_duckduckgo_kw_research](buscar_en_duckduckgo_kw_research/) | Python (Colab) | Keyword research con DuckDuckGo exportando a Sheets |

## Cómo usar

Para los scripts de Apps Script: abre tu Google Sheet → Extensiones → Apps Script → pega el contenido del archivo `.gs` correspondiente.
